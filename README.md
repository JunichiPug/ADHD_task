# README

## 1. サービス概要


- このサービスはどんなサービスか（3行以内）

ADHD向けのやらないといけないこと（タスク）をドーナツグラフで表示し<br />
アナログストップウォッチの針が動くようにカウントアップしてタスクをこなす<br />視覚的に行動を促し
「あとでやろう」を流れるように「いまやろう」に変えるサービスです

## 3. 課題の整理（表面的になっていないか）

  

### 3-1. 表に見えている困りごと

  - プライベートであれば<br />
出勤までの準備<br />
家族やパートナーなどの大切な人に不信感を抱かれる<br />
（大切な人はADHDのパートナーに真剣に教えても覚えてもらえないなど）<br />
帰宅後の就寝までの流れ
  
  - 仕事であれば<br />
上司の指示やお客様からのご依頼を忘れてしまう<br />
契約など大切な場面での準備不足<br />
（ADHDという言い訳ができない）

  

---

  

### 3-2. 本当に解決したい課題は何か

 - プライベートだと<br />
  ADHDの方（1人でもパートナーと一緒でも）が楽に愉しく幸せな時間を過ごすこと
```
  伝える（教える）
  　　↓
  覚えてない（理解が出来ていないなど）
  　　↓
  不信感を抱く（不快な思いや苛立ちなど）
  　　↓
  言い争いになる（喧嘩になる）
  　　↓
  お互いの心の距離が離れていく（違う道を歩き出す）
  　　↓
  パートナーとの別れ
  ```



  - 仕事だと<br />
  ADHDの方が少しでも楽に業務を行なえる
  ```
  上司からの指示（お客様からのご依頼）
  　　↓
  覚えてない（理解が出来ていないなど）
  　　↓
  怒られる（お客様からクレームになる）
  　　↓　　
  信用を失う（上司やお客様は適当に仕事をしていると感じる）
  　　↓
  上司から見放される（お客様から担当変更や契約解除などがおきる）
  　　↓
  居心地が悪くなる
  　　↓
  会社を辞める
  ```

## 7. このアプリで実現すること

  

### MVPで作る機能

- ユーザー認証機能
- メールアドレスによる新規登録、ログイン、ログアウト機能。
- タスクのグループ化（朝の準備、契約の準備などグループ名の自由入力）
- タスク機能（入力、編集、削除）
- タスクのドーナツグラフ化（スタートボタン、ストップボタン、戻る機能）
- 覚え書き機能（メモ）

### 本リリースで作る機能
- 音声入力（タスクの入力、メモの入力）
- スマホカメラを使用した（タスクの入力、メモの入力）
- タスクの開始時間で重要度の自動設定
- AIを使用した困りごとのQ&A
- ドーナツグラフで予定通りタスクを完了した時のご褒美
- Googleアカウントでのログイン
- RSpecの構築

## 10. 技術スタック（手段としての技術）

  

### 10-1. 使用予定の技術

- 開発言語：Ruby3.4.x
- フレームワーク：Ruby on Rails7.2.x
- データベース：PostgreSQL
- デプロイ先：Render
- 開発環境：Docker
- 認証：Devise
- 外部API連携：Google OAuth 2.0（Googleログイン）
- CSS／UIフレームワーク：Tailwind CSS
- その他ライブラリ／Gem
    - RSpec
    - Devise（ユーザー認証）
    - TailwindCSS（UI）
    - Ransack（検索機能）
    - kaminari（ページネーション）


  

---

  

### 10-2. 技術選定の理由

  

- なぜこの技術を使うのか<br />
Ruby on Railsは開発速度が速く、個人開発のWebサービスに適しているため

- 今回チャレンジしたい点<br />
タスク機能<br />
タスクをドーナツグラフ化する<br />
ドーナツグラフ化した予定を経過した時間は色付きで表示され、残り時間との比率を視覚的に把握できるようにする

- 不安な点<br />
タスク機能のデータベース設定が不安<br />
タスクをドーナツ化できるか不安<br />
